# InterviewLens

InterviewLens is an interview practice application that helps students prepare for Technical, HR, and Managerial interviews.

## Features

- Technical, HR, and Managerial interview modes
- Programming language selection for technical interviews
- Beginner, Intermediate, and Advanced difficulty levels
- Target role selection
- Custom number of questions
- Camera and microphone based interview recording
- Speech-to-text transcription
- Answer evaluation and feedback
- Correct answer/reference answer
- Retry option
- Recorded answer playback and download
- Final interview performance report

## Tech Stack

- React
- Vite
- JavaScript
- CSS
- MediaDevices API
- MediaRecorder API
- Speech Recognition API
- Lucide React

## Running Locally

Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Go to the project folder:

```bash
cd InterviewLens
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the URL shown in the terminal, usually:

```text
http://localhost:5173
```

Allow camera and microphone permissions when prompted.

## Build

```bash
npm run build
```

The production files will be generated in the `dist` folder.

## Browser

For the best experience, use:

## Note

Speech-to-text accuracy depends on the browser and microphone.

Recorded interview videos can be played back and downloaded during the interview session.
